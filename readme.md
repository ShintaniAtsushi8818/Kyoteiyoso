# BOAT AI Predictor MVP

ブラウザだけで動く競艇予想アプリのMVPです。

## ファイル構成

- index.html
- style.css
- app.js

## 起動方法

1. フォルダをPCへ展開
2. `index.html` をダブルクリック
3. ブラウザで起動

## 現在できること

- 開催場の選択
- 1R〜12Rのレース選択
- 6艇の選手・勝率・モーター・ST・展示データ表示
- 独自AIスコア計算
- 1着推定確率
- 3連単120通りから上位8点をランキング
- 予想理由表示
- LocalStorageへの予想履歴保存
- スマホ表示対応

## 現在のデータについて

現段階ではサンプルデータです。
`app.js` の `sampleData` と `createRaces()` がデータソースになっています。

次の段階では、ここを以下のどちらかに置き換えます。

- BOAT RACE公式データを取得するバックエンド
- 外部APIからJSON取得

## AIスコア

現在はルールベースです。

- コース: 24%
- 全国勝率: 23%
- 当地勝率: 12%
- モーター2連率: 18%
- 平均ST: 13%
- 展示タイム: 10%

将来的にはLightGBM / XGBoost / CatBoostなどの機械学習モデルへ置き換え可能です。
